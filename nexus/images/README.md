- `banner.jpg` - the mod page background image (1300x372).
- `01-tlsa_wa_thumb.jpg` - the gallery image chosen as the mods-grid thumbnail (1920x1080).
- `02-tlsa_wa_before.jpg` - gallery "before" (1920x1080): the inventory with the mod disabled, ammo at its real weight (total 210/165 encumbrance).
- `03-tlsa_wa_after.jpg` - gallery "after" (1920x1080): the same inventory with the mod on, all ammo at 0 (total 168/165).

The before/after gallery pair is on the same stacks, so the effect is obvious.
