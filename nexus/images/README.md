# Images

Nexus page images, tracked in the repo.

Sizes follow the Nexus editor's recommendations: thumbnail 1300x372, gallery images 1920x1080.

- `thumbnail.jpg` - the page thumbnail (1300x372 banner): the ammo tab cropped, every stack at 0 weight.
- `01-before-vanilla-weight.jpg` - gallery "before" (1920x1080): the inventory with the mod disabled, ammo at its real weight (total 210/165 encumbrance).
- `02-after-weight-zero.jpg` - gallery "after" (1920x1080): the same inventory with the mod on, all ammo at 0.

The two gallery shots are a before/after pair on the same stacks, so the effect is obvious.
